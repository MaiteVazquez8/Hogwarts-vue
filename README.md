# Hogwarts

Hogwarts es una pequeña web informativa sobre la escuela de magia y hechicería de Hogwarts. La página presenta una introducción a la escuela, información sobre el castillo y una estructura pensada para ir ampliando con casas, fundadores y personajes destacados.

## Cómo correr el proyecto

1. Instala las dependencias:

```sh
npm install
```

2. Inicia el servidor de desarrollo:

```sh
npm run dev
```

3. Abre la URL que aparezca en la terminal (por lo general, http://localhost:5173).

## Construir para producción

```sh
npm run build
```
